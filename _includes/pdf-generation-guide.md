# PDF Generation Guide

Your CV page now has professional PDF generation capability!

## How it Works

1. **Click "Download as PDF"** button on your CV page
2. **Browser print dialog opens** with optimized formatting
3. **Choose "Save as PDF"** in the destination dropdown
4. **Adjust settings if needed** (margins, layout)
5. **Click "Save"** to download your PDF

## Print Settings for Best Results

### Recommended Settings:
- **Destination**: Save as PDF
- **Layout**: Portrait
- **Paper Size**: Letter (US) or A4
- **Margins**: Default or Custom (0.75")
- **Scale**: 100%
- **Options**: Enable "Background graphics" (if available)

### Browser-Specific Tips:

**Chrome** (Recommended):
- Best formatting and layout control
- Enable "Background graphics" for full styling
- Use "More settings" to adjust margins

**Firefox**:
- Good PDF quality
- May need to enable background colors in print settings

**Safari**:
- Clean output
- Check "Print backgrounds" in print dialog

**Edge**:
- Similar to Chrome
- Good compatibility with print styles

## Features of the Generated PDF:

✅ **Professional Formatting**: Clean, academic layout
✅ **Contact Information**: Centered header with your details
✅ **Section Headers**: Clear hierarchy with proper spacing
✅ **No Website Elements**: Navigation, sidebar, and buttons hidden
✅ **Print-Optimized Typography**: Readable fonts and sizes
✅ **Proper Page Breaks**: Sections don't break awkwardly
✅ **Academic Standard**: Professional CV appearance

## Troubleshooting:

**If text is too small**: Increase scale to 110-125%
**If margins are wrong**: Use custom margins (0.75" recommended)
**If formatting is off**: Enable background graphics/colors
**If missing content**: Check that all content loads before printing

The PDF will automatically include your most current information from the website, so it's always up-to-date!
