 # 링크 버튼 사용 가이드
 
각 논문 아래의 링크는 Markdown 기본 형식으로 작성되어 있습니다. 가능한 링크 라벨:
 
- `[Preprint]` — arXiv, SSRN, OSF 등의 프리프린트
- `[Published]` — 출판사 공식 DOI 링크
- `[PDF]` — 직접 PDF 다운로드 링크
- `[Code]` — GitHub 저장소
- `[Slides]` — 발표 슬라이드
- `[Data]` — 데이터 저장소
- `[Poster]` — 포스터 세션 PDF
## 링크 작성 예시
 
```markdown
- **Park et al.** (2023) "Some Title." *Journal*.
  [[Preprint](https://arxiv.org/abs/2310.13713)] [[Published](https://doi.org/10.xxxx/xxxx)] [[Code](https://github.com/youngjour/some-repo)]
```
